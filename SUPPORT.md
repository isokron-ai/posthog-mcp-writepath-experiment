# Support

No support is offered for this repository. It is a research experiment by [IsoKron](https://isokron.ai), published so
the changes can be inspected and the measurement reproduced. See [EXPERIMENT.md](EXPERIMENT.md).

- **Your reproduction disagrees with ours:** please open an issue with the task, model, client version, build hashes and
  counts (tool calls, turns, failed calls, correctness). These reports are welcome.
- **Help using PostHog's MCP server:** use the official project and its documentation,
  https://posthog.com/docs/model-context-protocol. This repository is not affiliated with PostHog.

This build is based on upstream commit `7b516983` and is not maintained against later upstream commits.
